# Retail Sales & Performance Dashboard

## 📊 Project Overview

An interactive Retail Sales & Performance Dashboard created using Microsoft Power BI.

The dashboard helps analyze sales, profit, customers, orders, targets, products, stores, returns and marketing performance.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Excel

## 📈 Dashboard KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Average Order Value (AOV)
- Profit Margin %

## 📊 Dashboard Analysis

- Sales by Month
- Sales by Category
- Profit by Category
- Profit by State
- Top Stores by Sales
- Top Products by Sales
- Sales & Profit Trend
- Monthly Sales vs Target
- Sales by Payment Mode
- Sales by Channel
- Returns by Reason
- Marketing Spend Analysis

## 🔎 Interactive Filters

- Region
- Category
- Year
- Quarter
